Welcome to **SBCollected**, a personal portfolio and repository of knowledge focusing on technology leadership success, supply chain execution, and operational workflow strategy. 

## 📋 Overview
This site functions as a centralized hub to document successful methodologies, tactical frameworks, and continuous improvement strategies. It serves to show practical execution models for complex enterprise problems.

## 🗂️ What's Included: Discussions & Portfolio

* **Product & Systems Strategy:** Articles and frameworks on serving as a de facto product manager—translating complex operational challenges into technical requirements, architecture blueprints, and execution roadmaps.
* **Enterprise Integrations:** Deep-dives and case studies on architecting cross-functional workflows across enterprise ERP platforms, high-volume WMS environments, and 3PL integrations.
* **Operational Leadership & Change Compliance:** Insights and practical templates for building clear technical documentation, compliance frameworks, and training programs that ensure long-term user adoption.
* **Operational Case Studies:** Deep dives into high-impact workflow optimizations and system integrations.
* **Product Manager Toolbox:** Practical resources, prioritization frameworks, and templates for managing lifecycle development.
* **Enterprise Strategies:** Documentation surrounding warehouse systems, legacy architecture migration, and supply chain logistics.

* **Hosting Platform:** [GitHub Pages](https://pages.github.com/)

## 💻 Local Development
If you want to pull this repository and run the website locally on your computer to preview changes before pushing:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd SBCollected
   ```

2. **Install dependencies:**
   ```bash
   bundle install
   ```

3. **Run the local server:**
   ```bash
   bundle exec jekyll serve
   ```
   Open your browser and navigate to `http://localhost:4000/SBCollected/`.
